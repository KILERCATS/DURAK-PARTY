# Дурак Party

Браузерная игра «Подкидной дурак» для двух игроков с комнатой по ссылке. Красивый адаптивный стол, простая анимация, ручная и автоматическая сортировка, колода 36 карт, козыри, игра по сети.

## Запустить на компьютере

Установи Node.js версии 18+, открой терминал в папке проекта и выполни:

```bash
npm install
npm start
```

Перейди на http://localhost:3000

## Опубликовать в интернете через GitHub + Render

1. Распакуй архив. На https://github.com создай новый репозиторий, например `durak-party`.
2. Нажми в репозитории **Add file → Upload files** и загрузи содержимое папки проекта (именно `package.json`, `server.js`, `public` и др., а не ZIP). Нажми **Commit changes**.
3. Зайди на https://dashboard.render.com, нажми **New → Web Service**, подключи свой GitHub и выбери репозиторий.
4. Настройки: **Language: Node**, **Build Command: `npm install`**, **Start Command: `npm start`**, **Instance Type: Free** (если доступен).
5. Нажми **Deploy Web Service**. Открой выданный адрес `https://...onrender.com`.
6. Введи имя, нажми **Создать комнату → Скопировать приглашение**. Отправь ссылку другу. Друг открывает её, вводит имя и нажимает **Войти по коду**, затем **Присоединиться**.

Не используй GitHub Pages: там нет Node.js-сервера для синхронизации карт. Нужен именно Render Web Service (или другой Node.js-хостинг).

## Ограничения прототипа

- Комнаты хранятся в оперативной памяти сервера и исчезают при перезапуске, включая засыпание бесплатного сервера Render.
- Упрощённый ход: после нажатия «Забрать карты» защитник забирает их сразу, без фазы дополнительного подкидывания. «Бито» подтверждает атакующий после покрытия всех карт.
- Игра рассчитана на **двух игроков**, без ставок и денег, и на один серверный процесс.
